Ready to play?

From download
to adventure.

It's free to jump in. Follow these quick steps and you'll be placing your first block in no time.

01

Get the latest release

Visit GitHub Releases and download the BlockyCubes-*.zip game package from its Assets section.

02

Extract the whole ZIP

Unzip the game into a folder on your Windows PC. Keep the game files and assets and libs folders together.

03

Check that Java is installed

BlockyCubes needs Java 21 or newer. If you don't have it, install it from Eclipse Temurin.

04

Start the game!

Double-click BlockyCubes.vbs in the extracted folder. Create a world and enjoy.

Having trouble? Try run-debug.bat in the game folder, make sure Java is on your PATH, or report an issue on GitHub.
